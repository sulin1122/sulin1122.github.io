用 CSS Grid 实现手机与桌面自适应的作品列表

同一组作品，在桌面上可以并排比较，在手机上则需要更顺畅的阅读顺序。这篇笔记记录本站作品列表的布局方式。

先确定卡片的内容与顺序

每张卡片包含封面、项目名称、用途摘要、案例链接和体验或源码入口。小屏幕需要完整保留这些内容，再调整它们的排列方式。

本站桌面作品区采用两列：个人网站和待办清单并排，视觉实验占满一行。这个顺序同时保存在 HTML 中，手机改成单列时仍可以自然阅读。

桌面端建立两列 Grid

Grid 负责卡片之间的布局，卡片内部可以继续使用 Flex 排列标题、年份与操作入口。关键样式如下：

.project-grid {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 53px 28px;
}

.project-wide {
  grid-column: 1 / -1;
}

minmax(0, 1fr) 让列可以收缩到可用空间，避免内部较长的文字把整个网格撑宽。

手机端改为单列并重置跨列

本站在不超过 760px 的屏幕上切换作品列表。改变列数时，同时重置视觉实验的跨列设置：

@media (max-width: 760px) {
  .project-grid {
    grid-template-columns: minmax(0, 1fr);
    gap: 38px;
  }

  .project-wide {
    grid-column: auto;
  }
}

断点需要根据内容拥挤程度调整。检查时可以逐渐缩小窗口，观察项目名称、筛选按钮和封面文字是否仍能清楚阅读。

图片尺寸与文字也要一起调整

图片保留 width 和 height，通过 CSS 控制显示尺寸；同一图片提供多个宽度，让浏览器按布局与设备像素密度选择资源。封面若使用裁切，也要确认重要内容没有被切掉。

项目名称和摘要允许换行，操作链接可以折到下一行。较长的英文地址和代码需要单独处理，防止产生页面级横向滚动。

用实际内容检查布局

  • 从桌面到手机宽度逐步检查，确认列数与卡片顺序。
  • 检查较长中文标题、英文技术名和筛选按钮。
  • 使用键盘访问案例和体验链接，确认焦点清楚可见。
  • 关闭 JavaScript，确认作品摘要与详情链接仍可阅读。

布局检查与图片加载检查需要分别进行；页面放得下，并不意味着图片文件已经足够小。
