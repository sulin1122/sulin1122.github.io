JavaScript 环形作品画廊：定位、旋转与暂停控制

环形画廊的重点除了让卡片动起来，还包括让访问者停得住、看得清，并能在手机上继续使用。

把卡片均匀分配到椭圆轨道

画廊先确定中心位置，再使用横向半径和纵向半径形成椭圆。每张卡片分配一个角度，角度由卡片编号和当前旋转角共同决定。

const angle = index / orbitCards.length * Math.PI * 2 + orbitAngle;
const x = Math.cos(angle) * rx;
const y = Math.sin(angle) * ry;
const tilt = Math.sin(angle * 1.7) * 8;

card.style.transform =
  `translate(-50%, -50%) translate(${x}px, ${y}px) rotate(${tilt}deg)`;

卡片自身保持绝对定位，平移和倾斜交给 transform。窗口尺寸变化时重新计算轨道半径。

用时间差推进旋转角度

requestAnimationFrame 提供下一帧回调。项目根据相邻帧的时间差推进角度，并限制单次时间差，避免切换回页面时突然跳过很长一段轨道。

更新位置之前，还会检查画廊是否可见、页面是否处于前台、是否为桌面布局，以及当前有没有暂停。循环可以继续等待下一帧，卡片位置则只在需要运动时变化。

为指针、键盘和主动暂停分别处理

指针进入画廊时暂停，离开后根据其他状态决定是否继续；键盘焦点进入画廊也会暂停。画廊中间的控制按钮提供明确的暂停和恢复操作，并同步更新 aria-pressed 与按钮文字。

快速预览弹窗关闭后，焦点回到打开它的卡片。这样用户可以继续检查其他作品，不必重新寻找浏览位置。

尊重减少动态效果的偏好

页面读取 prefers-reduced-motion: reduce，为偏好减少动画的访客暂停动态。顶部动态按钮也可以主动控制页面，选择结果保存在当前浏览器。

暂停时仍可浏览项目卡片、阅读摘要与打开独立案例页。内容与导航不依赖持续运动。

手机上切换为横向卡片列表

当屏幕不超过 760px 时，JavaScript 不再更新卡片的环形 transform；CSS 将卡片放入横向 Flex 列表，并使用 overflow-x: auto 与 Scroll Snap 提供滑动对齐。

此时每张卡片有固定的阅读宽度，用户直接左右滑动选择作品。详情内容继续通过案例链接访问。
