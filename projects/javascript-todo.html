可以直接体验哪些功能

打开 JavaScript 待办清单，添加一项任务，选择学习、项目或生活分类，再尝试完成、搜索和编辑。清单同时提供全部、待完成和已完成状态筛选，以及任务数量和完成进度。

编辑可以通过按钮或双击任务文字进入，Enter 保存，Escape 取消；输入中文时会检查组合输入状态，避免回车选词意外提交。删除后会显示撤销入口，保留 12 秒恢复机会。

用任务数组驱动页面更新

任务使用 id、text、done 和 category 四个字段表示。任务数组保存数据，状态筛选、分类筛选和搜索词分别保存当前视图条件，render() 根据这些数据更新列表与计数。

{
  id: 'task-example',
  text: '完成作品集的手机布局检查',
  done: false,
  category: 'project'
}

页面使用 createElement 和 textContent 显示访客输入，任务文字作为文本呈现。编辑、勾选完成和删除都会先更新数据，再刷新显示。

组合分类、状态与搜索条件

筛选时三个条件同时生效：任务是否属于当前完成状态、是否属于当前分类，以及任务文字是否包含搜索词。搜索会去掉首尾空白并统一大小写，让英文词也可以自然匹配。

const visible = tasks.filter(task =>
  (stateFilter === 'all' ||
    (stateFilter === 'done' ? task.done : !task.done)) &&
  (categoryFilter === 'all' || task.category === categoryFilter) &&
  task.text.toLocaleLowerCase().includes(search)
);

条件没有匹配结果时显示空状态，用户可以继续切换筛选条件。添加新任务后会重置筛选，让刚添加的内容立即可见。

在当前浏览器保存和恢复任务

本项目使用键名 sulin.tasks.v2，通过 JSON.stringify() 保存任务数组，在重新打开页面时读取和解析。读取结果还会检查字段类型、文字长度和重复编号，避免直接信任已保存的数据。

存储读取和写入都放在 try...catch 中；浏览器禁止存储或空间不足时，页面会给出提示。更详细的处理见 localStorage 保存待办事项实践笔记。

编辑、删除与撤销如何衔接

删除前会记录任务的内容和原始位置。点击撤销后，把任务插回原来的位置，再保存并重新渲染。撤销窗口结束后，暂存记录会被清除。

同一浏览器的其他标签页更新清单时，页面会提醒刷新查看。当前实现没有自动合并并发修改。

使用边界与项目源码

任务只保存在当前站点、当前浏览器的本地存储中，没有上传服务器，也不提供登录、跨设备同步或数据备份。清理站点数据可能移除已保存的任务。

当前任务上限为 500 项，每项最多 120 个字符。在线体验待办清单，或 阅读 todo.js 项目源码。
