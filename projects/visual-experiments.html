先确定画面的表达方式

页面以深色首屏、米白内容区、橙红和荧光绿作为主要视觉元素。字体海报、星形装饰与待办缩略图使用 HTML 和 CSS 实现，作品说明使用可选择、可阅读的真实文字。

视觉装饰围绕个人作品展开；项目卡片同时提供内容摘要和明确链接，让访问者能从画面继续了解实际实现。

主视觉与参考素材的来源

首屏人物是为本网站创作的 AI 辅助 3D 概念视觉，不是苏林的真实肖像。素材提示词与使用说明保存在 ASSETS.md。

画廊中的宣传册与封面图片是排版学习参考，用于观察留白、图文关系和色彩搭配。它们在预览中标为参考素材，与原创网页项目分别说明。

环形作品墙如何运动

桌面端把卡片均匀分配到椭圆轨道上，JavaScript 使用 Math.cos() 与 Math.sin() 计算位置，再通过 CSS transform 更新平移和倾斜。

旋转只在画廊可见且允许动态时更新；指针悬停、键盘焦点进入或点击暂停，都可以停住画面。阅读环形画廊实现笔记。

为手机与减少动态偏好提供另一种呈现

屏幕宽度不超过 760px 时，环形轨道改为横向滑动列表，卡片通过 CSS Scroll Snap 对齐。用户可以直接滑到想看的作品。

页面读取 prefers-reduced-motion，并提供页面动态按钮。访客主动选择的动态偏好保存在当前浏览器中，方便下次访问时继续使用。
